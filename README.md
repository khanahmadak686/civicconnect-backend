## 🧩 Problem Statement

Citizens in urban areas lack a transparent, accessible channel
to report and track civic issues — potholes, water supply failures,
waste management problems — leading to unresolved complaints
and eroded public trust in municipal systems.

## 💡 Solution

CivicConnect is a full-stack web platform where citizens submit
grievances that are automatically routed to relevant municipal
departments. Admins manage resolution status; citizens receive
real-time updates — creating accountability at scale.

---

## ✨ Key Features

- 📍 Issue submission with category-based department routing
- 🔄 Real-time status tracking: Open → In Progress → Resolved
- 📊 Admin dashboard with grievance overview and analytics
- 🔐 Role-based access control (Citizen / Department Admin)
- 📱 Responsive UI — works across desktop and mobile
